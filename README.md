# Solutions For LeetCode
All solutions are separated into directories. You'll find the link to the
problem in its respective `README.md`. No subfolders are created for
language-specific solutions. You are expected to look at the file extension for
that.

# Naming Conventions
Solution files are named `sol`. If there are multiple solutions from the same
language, then they may contain a postfix such as `-N` where N is a digit.
